# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a


# Общее описание решение

- Данный проект представляет собой библиотеку для вычислени основных геометрических характеристик фигур: квадрата, круга, прямоугольника.
Библиотека состоит из 3 модулей:

- square.py - вычисления для квадрата.
- circle.py - вычисления для круга.

- Каждая функция принимает необходимые размеры (сторону или радиус) и возвращает числовое значение (площадь или периметр).

# Описание каждой функции с примерами вызова

## square.py

- Функция area(a) принимает число а (сторону квадрата), возвращает площадь квадрата (число а в квадрате).
- Параметры: a (int) - длина стороны квадрата
- Пример вызова: def area(5) = 25

- Функция perimetr(a) принимает число а (сторону квадрата), возвращает периметр квадрата (число а умноженное на 4).
- Параметры: a (int) - длина стороны квадрата
- Пример вызова: def perimeter(6) = 24

## circle.py

- Функция area(r) принимает радиус круга r, возвращает площадь круга.
- Параметры: r (int) - радиус круга
- Пример вызова: def area(5) = 78.53981634

- Функция perimetr(r) принимает радиус круга r, возвращает периметр круга (длину окружности).
- Параметры: r (int) - радиус круга
- Пример вызова: def perimeter(4) = 25.13274123
