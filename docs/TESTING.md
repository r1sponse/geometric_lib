# Лабораторная работа №4. Написание Unit-тестов

## План тестирования

### 1. Цели и задачи тестирования
*   **Цель:** Проверить корректность реализации функций вычисления площади и периметра для геометрических фигур (круг, квадрат, прямоугольник, треугольник).
*   **Задачи:** 
    *   Написать модульные тесты с использованием фреймворка `unittest`.
    *   Покрыть позитивные сценарии (передача корректных данных).
    *   Покрыть граничные случаи (нулевые значения).

### 2. Описание тестируемого продукта
Тестируемый продукт — это библиотека на Python, содержащая функции для расчета геометрических параметров. В модулях `circle.py`, `square.py`, `rectangle.py` и `triangle.py` реализованы функции `area()` (площадь) и `perimeter()` (периметр).

### 3. Область тестирования
Тестированию подлежат функции всех четырех модулей:
*   `circle.py` — функции площади и длины окружности.
*   `square.py` — функции площади и периметра квадрата.
*   `rectangle.py` — функции площади и периметра прямоугольника, включая проверку нулевой стороны.
*   `triangle.py` — функции площади и периметра треугольника.

### 4. Стратегия тестирования
Используется функциональное тестирование. Применяются следующие техники:
*   **Позитивное тестирование:** передача корректных значений и сравнение результатов с эталонными математическими расчетами.
*   **Тестирование граничных значений:** проверка работы функций при передаче нулевых значений (например, прямоугольник с одной стороной 0).
*   Для дробных значений (круг) используется метод `assertAlmostEqual` для сравнения с заданной точностью.

### 5. Критерии приемки
Тестирование считается успешным, если:
*   Написаны тесты для всех четырех фигур.
*   Все тесты завершаются статусом `OK` (без ошибок и падений).
*   Исходный код фигур не был изменен в процессе написания тестов.

### 6. Ожидаемые результаты
Ожидается, что все написанные Unit-тесты пройдут успешно, подтверждая корректность формул в исходном коде.
